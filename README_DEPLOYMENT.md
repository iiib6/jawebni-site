# دليل تشغيل ورفع موقع جاوبني (Jawebni)

هذا الدليل يشرح كيفية تشغيل السيرفر الخلفي (Backend) القائم على إطار عمل Flask محلياً وكيفية رفعه على منصات الاستضافة السحابية ليكون جاهزاً للجمهور.

---

## 🛠️ التشغيل المحلي (Local Running)

### 1. المتطلبات الأساسية
تأكد من تنصيب لغة بايثون (Python 3.8 أو أحدث) ثم قم بتثبيت مكتبة Flask عن طريق موجه الأوامر:
```bash
pip install Flask
```

### 2. إعداد المتغيرات البيئية
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع، وضف داخله مفتاح الـ API الخاص بـ Gemini:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(ملاحظة: هذا الملف محمي ومضاف إلى `.gitignore` تلقائياً لمنع رفعه على مستودعات الأكواد العامة)*

### 3. تشغيل السيرفر
لتشغيل الخادم، اكتب الأمر التالي:
```bash
python server.py
```
سيبدأ الخادم بالعمل على الرابط المحلي: **[http://localhost:8000](http://localhost:8000)**

---

## ☁️ الرفع والاستضافة السحابية (Production Deployment)

لرفع الموقع ليعمل 24 ساعة للجمهور، نوصي باستخدام خيارين رئيسيين:

### الخيار الأول: الاستضافة على Render أو Railway (موصى به لـ Python + SQLite)
منصات مثل **[Render](https://render.com/)** أو **[Railway](https://railway.app/)** تتيح لك تشغيل تطبيقات بايثون بسهولة وتوفر قرص تخزين لحفظ قاعدة بيانات SQLite.

1. قم برفع كود المشروع إلى مستودع خاص (Private Repository) على GitHub.
2. اربط حساب GitHub الخاص بك بمنصة Render أو Railway.
3. قم بإنشاء تطبيق ويب جديد (Web Service) واختر المستودع.
4. **إعدادات البيئة (Environment Variables):**
   * أضف متغيراً بيئياً باسم `GEMINI_API_KEY` وضع قيمته (مفتاح الـ API مالتك).
5. **أمر التشغيل (Start Command):**
   * لـ Render: أضف أمر التشغيل `python server.py` أو استخدم خادم ويب احترافي عبر تثبيت `gunicorn` واستدعائه: `gunicorn server:app`.
6. سيقوم السيرفر بالعمل تلقائياً وسيعطيك رابطاً آمناً (HTTPS) مجاناً!

### الخيار الثاني: الاستضافة السحابية الكاملة (VPS مثل DigitalOcean / Hetzner)
إذا كنت تفضل إدارة الخادم بالكامل بنفسك:
1. قم بحجز خادم Linux (Ubuntu).
2. قم بتنصيب بايثون وFlask.
3. قم بتشغيل التطبيق خلف خادم ويب عكسي مثل **Nginx** ومسير عمليات مثل **Gunicorn** لضمان استقرار التشغيل وتفعيل شهادة الأمان SSL (Let's Encrypt) مجاناً.

## 📊 قاعدة البيانات وإدارة العملاء المحتملين (Leads Database)
* يتم حفظ معلومات العملاء الذين أتموا الحجز بنجاح داخل قاعدة بيانات محلية باسم `leads.db` (بصيغة SQLite).
* قاعدة البيانات تُنشأ تلقائياً في أول تشغيل للموقع.
* يمكنك قراءة البيانات وتصديرها باستخدام أي قارئ لقواعد البيانات أو عن طريق سكربت بسيط في بايثون.
